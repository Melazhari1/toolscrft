## Project Overview
ToolsCraft is a Laravel 13 web application providing a suite of online developer and content tools. The application uses Inertia.js with Vue 3 for the frontend and Laravel for the backend, styled with Tailwind CSS and built with Vite.

**Use Cases**: Text analysis, domain checking, data conversion, URL encoding, CSS generation, slug generation, UTM parameter creation

## Technology Stack

### Backend

 & Patterns

### PHP/Laravel Patterns
**Routes** (routes/web.php)
- Use named routes: `Route::get('/path', [Controller::class, 'method'])->name('name')`
- Route groups for related functionality
- Naming convention: `route-name` (kebab-case)

**Controllers** (app/Http/Controllers/)
- One controller per tool/feature
- Action methods return `inertia('PageName', $props)` response
- Type hints on all method parameters
- Naming: `*Controller` suffix (TextalyzerController, DomainExpiryController)

**Models** (app/Models/)
- Extend `Illuminate\Foundation\Auth\User as Authenticatable`
- Use PHP 8 attributes: `#[Fillable(['field1', 'field2'])]`
- Use `#[Hidden(['password'])]` for sensitive fields
- Implement HasFactory for testing

**Database**
- Migrations: `database/migrations/YYYY_MM_DD_HHMMSS_action.php`
- Run: `php artisan migrate`
- Factories: `database/factories/UserFactory.php`
- Seeders: `database/seeders/*.php`

**Namespace Structure**
- `App\Http\Controllers\` - Request handlers
- `App\Models\` - Database models
- `App\Providers\` - Service providers
- `App\Console\Commands\` - Artisan commands
- `Database\Factories\` - Model factories
- `Database\Seeders\` - Database seeders
- `Tests\Feature\`, `Tests\Unit\` - Test classes

### Vue 3 + Inertia.js Patterns
**Page Components** (resources/js/Pages/)
- One Vue file per route
- Receives props from controller
- Naming: `PageName.vue` (PascalCase)

### Adding a New Tool
**Steps to follow:**
1. Create controller: `php artisan make:controller ToolNameController`
2. Define route in `routes/web.php`: `Route::get('/tool-path', [ToolNameController::class, 'index'])->name('tool.index');`
3. Create Vue component: `resources/js/Pages/ToolName.vue`
4. Return from controller: `return inertia('ToolName', $data);`
5. Add tests in `tests/Feature/` and `tests/Unit/`

### Modifying Database Schema
1. Create migration: `php artisan make:migration create_table_name`
2. Edit migration in `database/migrations/`
3. Run migration: `php artisan migrate`
4. Create model if needed: `php artisan make:model ModelName`
5. Create factory: `php artisan make:factory ModelNameFactory --model=ModelName`

### Creating a Form/API Endpoint
1. Add POST route: `Route::post('/endpoint', [ControllerName::class, 'store'])->name('action');`
2. Create form in Vue component with `useForm()` hook
3. Submit with `form.post('/endpoint')`
4. Handle validation errors with `form.errors`
5. Add tests in `tests/Feature/`

### Styling a Component
- Use Tailwind utility classes: `class="bg-blue-500 p-4 rounded-lg"`
- Check `tailwind.config.js` for custom colors/spacing
- Use responsive prefixes: `md:bg-blue-600`
- Use dark mode: `dark:bg-slate-900`

### Debugging Issues
- Check `storage/logs/laravel.log` for server errors
- Use `php artisan tinker` for interactive debugging
- Check browser console for frontend errors
- Use `php artisan pail` for real-time logs
- Add `dd($var)` or `dump($var)` in PHP for debugging

## API Response Patterns

### Returning Data from Controller
```php
// Return Inertia page with data
return inertia('PageName', [
    'users' => User::all(),
    'count' => 42,
    'message' => 'Success'
]);

// Redirect to another page
return redirect()->route('home');

// Redirect with data
return redirect()->route('home')->with('message', 'Success!');
```

### Vue Component Receiving Props
```javascript
defineProps({
    users: Array,
    count: Number,
    message: String
});
```
